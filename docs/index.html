Mundial de Parejas
Parejas activas: - En grupos: - Campeonas: -

Cada dupla se forma automaticamente con jugadores que comparten equipo. Si un jugador aparece en varias duplas, solo queda activa la pareja que esta mas lejos. Para mejorar pareja, tiene que haber ganado mas veces con alguien que no este ocupado en otra dupla activa. Si un jugador juega 5 partidos y su pareja no juega ninguno, esa dupla queda congelada y deja libre al jugador activo. Una pareja necesita 2 victorias para avanzar, 2 derrotas para caer, y si despues de 3 partidos no se define usa moneda.

Presiona "Procesar Mundial" para generar las parejas
